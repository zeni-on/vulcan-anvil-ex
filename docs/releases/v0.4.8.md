# Vulcan-Anvil Ex v0.4.8

Released: 2026-06-15

`v0.4.8` is a Product profile stabilization patch. It tightens the Product release path without making Product projects look like Audit projects.

## Highlights

- Made `release-pr --dry-run` profile-aware for Product projects.
- Preserved Product Build Wave related IDs such as `SCN`, `API`, `DATA`, and `REG` during status/session refresh.
- Replaced placeholder Product ADR rows with an explicit `ADR-NONE` empty-state.
- Added regression smoke checks for Product release body evidence, Product Build Wave related IDs, and Product ADR empty-state.

## Why It Matters

Product profile projects use `docs/product/` as their working source of truth. A Product release candidate should not look incomplete simply because audit-only QA or traceability artifacts are absent.

This release also removes a small but confusing workflow friction: new Product projects no longer carry `ADR-001 | TBD` as a fake decision. If no architecture decision has been made yet, `ADR-NONE` is the correct state.

## Upgrade Notes

Run:

```powershell
python vulcan.py upgrade
```

After upgrading Product projects:

- check `docs/product/ADR_LOG.md`; replace any stale `ADR-001 | TBD` placeholder with `ADR-NONE` if no real decision exists;
- run `python vulcan.py status --check` and confirm the working tree stays clean;
- run `python vulcan.py release-pr --dry-run` at Gate 5 and confirm Product evidence points to `docs/product/`, backlog, and the Gate 5 approval document.
