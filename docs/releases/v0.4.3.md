# Vulcan-Anvil Ex v0.4.3

Release date: 2026-05-31

`v0.4.3` is a stabilization patch for Run input quality and Gate 4 QA interpretation. It keeps the `v0.4.2` worker watchdog model, then tightens how workers receive trace context, how QA execution results are read, and how final verification status is reflected in the traceability matrix.

## Highlights

- `run-new` and `wave-start` now support trace-seed enrichment for Run drafts.
- Gate 4 `check-trace` now reads QA Test Result execution status before falling back to Gate 3 Test Cases.
- QA execution parsing only counts real execution IDs such as `UT-001`, `IT-001`, `PT-001`, and scenario-level `UI-001-01`.
- Documentation now separates the roles of Gate 3 Test Cases, Gate 4 Test Result, and Traceability Matrix.
- `qa-fix-loop` Run contracts are clearer and remain worker-owned.
- Dashboard Agent watchdog labels are clearer for active, quiet, stalled, and hard-timeout workers.

## Run Trace Seed

Run drafts can be created from a representative trace ID:

```powershell
python vulcan.py wave-start BW-001 --title "회원가입 API 구현" --trace-seed REQ-001-01
```

The generated Run draft receives recommended `related_ids`, `target_contracts`, and `source_documents.reference_on_demand`. The Orchestrator still has to confirm `scope.writable`, `interface_contract`, skeleton contracts, and verification commands before sending the Run to a worker.

## Gate 4 QA Results

Gate 3 Test Cases remain the plan and expected criteria. Gate 4 Test Result is the source of truth for actual execution status:

```text
Gate 3 Test Cases: Planned / criteria
Gate 4 Test Result: Pass / Fail / Not Run / Skipped / environment_blocked
Traceability Matrix: final requirement-level verification status
```

The QA parser ignores screen group IDs such as `UI-001` and evidence/comparison IDs such as `EV-UI-001-01` or `UICMP-001`. It only counts scenario-level UI execution IDs such as `UI-001-01`.

## Upgrade Notes

Existing projects can receive the new framework files with:

```powershell
python vulcan.py upgrade
```

After upgrade, QA-003 should update `DOC-QA-G4-002_Test-Result_v0.1.md` and the Traceability Matrix. It should not rewrite Gate 3 Test Case `Planned` rows into `Pass` rows just to satisfy `check-trace`.
