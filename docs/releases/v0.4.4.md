# Vulcan-Anvil Ex v0.4.4

Released: 2026-05-31

`v0.4.4` is a PoC profile and worker result recovery patch. It keeps the `v0.4.3` trace-seed, Gate 4 QA interpretation, and worker watchdog behavior, then reduces PoC Run input weight and makes Windows Antigravity runner responses easier to recover.

## Highlights

- PoC profile now defaults `run-new` and `wave-start` trace-context depth to 1 when `--trace-depth` is not explicitly provided.
- PoC Run drafts keep `source_documents` compact and avoid repeating Orchestrator-only Run protocol documents in worker input contracts.
- Build Wave Run drafts generated in PoC profile use a compact profile-aware path rather than the full audit-style Build Wave template.
- Antigravity runner transcript fallback now checks `transcript_full.jsonl` first and falls back to `transcript.jsonl`.
- Fixture smoke regression now verifies PoC compact Run generation and PoC trace-depth default behavior.

## PoC Compact Run Rules

PoC profile is not a lower quality mode. It keeps honest Gate, test, and evidence boundaries while reducing repetitive context.

- `audit`: trace depth default remains 2.
- `poc`: trace depth default is 1 unless overridden.
- `source_documents.read_first` stays limited to the project entry files, Delivery Profile rules, and current skill.
- `source_documents.reference_on_demand` is capped around directly related design/test/reference documents.
- `worker_run_sizing_policy`, `AGENT_RUN_PROTOCOL`, `RUN_INPUT_CONTRACT`, and `RUN_OUTPUT_CONTRACT` are not repeated inside PoC worker Run input contracts.

Details: [../reference/POC-RUN-COMPACT-STRATEGY.md](../reference/POC-RUN-COMPACT-STRATEGY.md)
