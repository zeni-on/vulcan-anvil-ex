# Vulcan-Anvil Ex v0.4.7

Released: 2026-06-14

`v0.4.7` is a patch release for Dashboard document comments and Orchestrator visibility. It keeps Markdown artifacts clean while letting users leave review notes directly from the Dashboard.

## Highlights

- Added Dashboard document comments for rendered Markdown artifacts.
- Stored comments as sidecar JSONL under `.vulcan/comments/comments.jsonl` instead of modifying source Markdown files.
- Added a sticky comments panel with `open` and `closed` states.
- Normalized legacy comment states (`resolved`, `converted`, `stale`) to `closed` when reading existing sidecar records.
- Added `dashboard_comments` to `python vulcan.py status` and `status --json` so the Orchestrator can see user notes before Gate, Run, QA, or release work.
- Updated Codex guidance so Dashboard comments are checked as part of the Orchestrator start routine.

## Why It Matters

The Dashboard is now more than a passive viewer. Users can mark questions, correction requests, FIND candidates, and CR candidates while reading artifacts. The Orchestrator can then pick those notes up from `status` without the user having to copy filenames and context back into chat.

Comments remain separate from the approved Markdown artifact. This avoids accidental document pollution while still keeping review intent in the project workspace.

## Upgrade Notes

Run:

```powershell
python vulcan.py upgrade
```

After upgrading generated projects:

- open the Dashboard and verify document comments are visible on Markdown artifacts;
- run `python vulcan.py status` and check whether `dashboard_comments` appears when comments exist;
- keep comment status to `open` or `closed`.
